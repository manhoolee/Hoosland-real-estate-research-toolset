# 报告交付质检清单

## 内容与数据

- [ ] 项目、范围、阶段、日期、目标一致
- [ ] 关键数字可回查到来源或底稿
- [ ] 合计、比例、单位、小数位和公式一致
- [ ] 事实、派生、推断、假设、建议已分层
- [ ] 关键风险有触发信号和动作
- [ ] 客户可读引用、数据截至日期、关键假设和适用限制完整
- [ ] 原始来源/主张账本、原始假设表和内部路径未混入正文

## 文件与视觉

- [ ] 目标文件实际生成并可打开
- [ ] 标题、目录、表格、图片和链接正常
- [ ] 桌面、移动、打印或投屏版本已抽查
- [ ] 无横向溢出、空白页、字体回退或图片缺失
- [ ] 来源、图注、版本和交付状态完整

## 放行

记录：质检日期、质检人、文件版本、P0/P1/P2/P3 数量、阻断项、复测结果和最终状态。
