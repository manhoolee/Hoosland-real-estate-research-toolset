# GitHub 模板参照：交付质检

本文件只记录参照方向，不复制第三方清单内容。

## 参照

- [Report QA Checklist](https://gist.github.com/QuayleApplications/77ce1feaabd0e58acb8c84b7355a7ba9)：借鉴把报告 QA 分为布局、数据内容、导出和交互等层次。
- [Google DESIGN.md lint/diff](https://github.com/google-labs-code/design.md)：借鉴设计 token 的结构校验、对比和可执行 JSON 结果。
- [Quarto Parameters](https://quarto.org/docs/computations/parameters.html)：借鉴参数化渲染与“同一模板、多项目/多版本”的复测方式。

## 吸收方式

每次交付同时保留输入版本、渲染命令、输出文件、截图/打印证据、问题等级、复测结果和放行人；不能只凭源码或“看起来生成成功”判定通过。
