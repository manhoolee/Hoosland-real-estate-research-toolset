# GitHub 模板参照：报告文案

本文件只记录参照方向，不复制第三方内容。

## 参照

- [GitHub Docs Style Guide](https://docs.github.com/en/contributing/style-guide-and-content-model/style-guide)：借鉴简洁、面向读者、按高价值场景组织内容的编辑原则。
- [Smashing Magazine Article Template](https://gist.github.com/vitalyfriedman/e7bbc6f671f05f96ed824ec1cc522389)：借鉴标题、快速摘要、正文和结尾资源的文章结构。

## 吸收方式

将地产报告文案固定为：标题/元信息 → 快速摘要 → 当前判断 → 证据与限制 → 具体建议 → 结尾行动与待决策。每一段都回答“给谁看、改变什么判断、依据是什么、下一步做什么”。
