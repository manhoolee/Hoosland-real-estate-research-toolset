# 地产研究协议 v2.1

## 范围树

先画：城市 → 板块/总体规划 → 出让期次 → 宗地 → 子地块 → 产品组团。每层创建唯一 `scope_id`，父层数字只能作为背景，不能自动成为子层输入。

## 研究深度

- 快速：1–2 个权威来源，识别方向和高风险缺口。
- 标准：法定文件 + 土地成交 + 至少 3 个直接/替代竞品，重要判断交叉验证。
- 审计：逐项来源账本、原始附件、时间序列、矛盾记录、计算底稿和人工复核。

样本不足时不伪造“至少 3 个”，而是报告实际样本及偏差。

## 来源顺序

法定规划/政府交易文件 → 登记或正式内部数据 → 企业正式披露 → 权威研究机构 → 主流媒体/平台 → 微信/销售说辞 → 匿名线索。

## 最小研究表

- 土地：用途、面积、容积率、计容、限高、密度、绿地、配建、地下、交付与监管条件；
- 市场：供应、成交、存量、去化、价格、面积/总价结构和数据期；
- 客群：来源地、职业/家庭、置换链、首付、月供、总价和触发事件；
- 风险：发生概率、影响、监测指标、责任人和动作。

## 结论强度

事实不自动等于建议。每条建议要写成：证据 → 推导 → 建议 → 适用前提 → 失效信号。
