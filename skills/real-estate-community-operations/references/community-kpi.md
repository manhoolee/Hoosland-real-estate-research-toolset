# 社群 KPI 字典 v2.1

| 指标 | 定义 |
|---|---|
| 有效触达率 | 在观察期内收到并可识别内容的去重人数 / 目标人数 |
| 活跃率 | 发生发言、报名、到场或共创等有效行为的去重人数 / 群内有效成员 |
| 活动到场率 | 实际签到人数 / 确认报名人数 |
| 推荐到访率 | 推荐客户实际到访人数 / 去重推荐人数 |
| 推荐成交率 | 推荐客户成交人数 / 去重推荐人数 |
| NPS | 推荐者占比减去贬损者占比，附样本量与回收率 |
| 退群率 | 观察期退出人数 / 期初有效成员 |

## 90 天试运行

第 1–2 周定义人群、价值主张和基线；第 3–6 周测试 2–3 类内容/活动；第 7–10 周保留有效机制并测试转化；第 11–12 周复盘投入、行为、口碑和销售影响。指标必须同时记录人力与现金成本。

## 隐私

手机号、家庭、资产和交易信息仅用于明确目的，限制访问、设定保留期；展示时聚合或脱敏，不把成员聊天内容直接用于外部宣传。
