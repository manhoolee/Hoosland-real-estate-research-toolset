# v2.1 输出模板

## 报告页首

```text
项目 / scope_id / 阶段 / 研究截至日期
研究深度：快速 / 标准 / 审计
交付状态：探索稿 / 讨论稿 / 可复核稿 / 可决策稿
经营目标：保利润 / 保现金流 / 保去化 / 保品牌
```

## 产策结论卡

```text
一句话产品定位：
证据/计算许可：L0 / L1 / L2
目标客群与支付边界：
面积段、户配与约套数：
价格及总价：下限 / 基准 / 上限
货值或去化敏感性：
差异化锚点与竞品隔离：

风险、失效信号与调整动作：
```

## 客户可读来源与假设附录

正式报告必须附客户可读的范围口径、引用或来源说明、数据日期、关键假设、适用限制、矛盾状态和待验证事项。原始来源账本、主张账本、假设表、公式底稿和内部文件路径留在工作区，不原样复制给读者；但必须能支撑客户可读附录中的每一项说明。

## 格式验证

- Markdown：链接和表格可读；
- HTML：本地资源可用、打印分页和移动端可读；
- Word/PDF/PPT：实际渲染后检查溢出、空白页、字体和图表；
- Excel：公式、单位、输入/输出区域和数据验证清晰。
