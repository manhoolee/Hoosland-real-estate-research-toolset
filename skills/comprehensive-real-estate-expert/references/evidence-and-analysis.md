# 证据与分析参考

## 研究主链

1. 城市与板块基本盘：人口、产业、财政、住房周期、政策。
2. 上位规划：法定规划、批复、在建、已建与概念叙事分层。
3. 地块空间条件：容积率、限高、密度、日照、退距、交通、配建和地质。
4. 供应与竞品：DIRECT / SUBSTITUTE / MISALIGNED / WATCHLIST。
5. 成交结构：面积段 × 总价段 × 时间，结合去化和存量。
6. 替代市场：二手、租赁、商办或其他可替代产品。
7. 客群洞察：泛客群、有效客群、可转化客群和支付边界。
8. 策略收敛：定位、产品、价格、节奏、风险和失效信号。

## 产品力评分

六维评分建议使用 1–5 分区间，不输出无来源的精确分数：

| 维度 | 观察项 |
|---|---|
| 区位力 | 真实通勤、已运营配套、板块认可度 |
| 规划力 | 总图、日照、通风、公共空间和密度 |
| 产品力 | 户型、功能效率、创新、梯户比和私密性 |
| 品牌力 | 开发商品牌、交付记录、物业预期 |
| 价格力 | 单价/总价、付款方式和性价比感知 |
| 服务力 | 售前、交付透明度、售后和物业增值 |

每一项记录：数据来源、截至日期、样本范围、评分依据和置信度。

## 在售复盘

按“成交客群还原 → 假设校验 → 漏斗诊断 → 产品价格适配 → 竞品拦截 → 渠道 ROI → 客诉口碑 → 经验升级”推进。重点识别到访、认筹、签约、回款的流失位置，以及客户流向竞品的具体原因。

## 社群评估

- NPS：季度测评，记录样本量和有效回收率。
- 转化：触达 → 报备 → 到访 → 认筹 → 成交，和销售系统交叉验证。
- 裂变：推荐人数、推荐到访、成交数和推荐转化率。
- 品牌：内容传播、用户生成内容、媒体价值、品牌溢价和复购/转介。
