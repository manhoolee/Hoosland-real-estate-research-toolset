## 行为变化

- 文件可访问性、报告格式配对和安全输出仍是成功交付的硬门禁。
- 任务清单改为审计投影：清单缺失、阶段竞态、任务未完成或清单提交失败只记录 `agent.checklist.close_warning`，不再拒绝已经通过文件和最终回复检查的交付。
- 文件与回复条目根据服务端实际成果和最终回复复核；未完成任务仍显示为 `incomplete`。
- 清单结构损坏、服务端无法持久化 run 状态、文件不可访问或必需配套格式缺失时仍会失败。
